## Чи зберігся задум під час передачі

**Частково.** Обґрунтування Planner дійшли до коду без змін: межі вікна включно, сортування `(due, id)`, параметр `today`, обробка дуже великого N через `date.max`, код 2 для помилки. Початковий намір Planner розкласти код по `domain.py` і `storage.py` тепер явно замінено задокументованим рішенням.

Головна причина в цьому рішенні — уникнути запиту на підтвердження від hook W1. Аргумент слабкий: такий запит лише просить підтвердження й нічого не забороняє. Але альтернатива і її наслідки записані чесно, тому як погоджене відхилення це прийнятно.

Чотири відкриті питання Planner автор задачі досі не закрив: значення `--days` за замовчуванням, текст для порожнього результату, фільтр `--course`, межі вікна в окремій нотатці-рішенні.
