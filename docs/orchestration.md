# Оркестрація ПР6

## Реальна задача

Додати команду `upcoming --days N`, яка показує відкриті задачі з терміном у наступні N днів. Значення N має бути невід’ємним. Команда не змінює базу.

## Ролі

1. **Planner** читає вимоги, guardrails і vault через MCP; передає ціль, план за файлами, обґрунтування й перевірки.
2. **Coder** реалізує код і тести за планом; передає фактичні зміни, мотиви й результати тестування.
3. **Reviewer** звіряє handoff із кодом, guardrails і тестами; повертає рішення та зауваження.

Ролі виконуються послідовними Claude Code сесіями (`--agent planner`, `--agent coder`, `--agent reviewer`). Між ними передається текстовий handoff з `docs/handoffs/`. Це свідомо вибраний механізм оркестрації, який підтримує методичка й не потребує паралельного запуску агентів.
