# ЗАВДАННЯ

## Застосунок

**StudyFlow** — локальна CLI-програма для керування навчальними задачами. Користувач — студент, який веде перелік завдань, термінів і статусів без сервера та реєстрації.

Функції: додати задачу, переглянути список з фільтрами, завершити задачу, отримати зведення, експортувати дані у CSV. Дані зберігаються у SQLite.

Стек: Python 3.12, стандартна бібліотека (`argparse`, `sqlite3`, `csv`), `pytest` для перевірок.

## Агентна IDE

Claude Code: локальний CLI із доступом до команд, проєктних інструкцій, MCP-серверів, hooks і skills. У межах роботи IDE відкриває лише цей репозиторій.

## Мета harness

Прискорити повторювані зміни StudyFlow та перевіряти їх за вимогами, архітектурою й актуальними нотатками vault.

## Цільові задачі агента

1. Додавати невеликі CLI-функції з тестами.
2. Проводити рев'ю змін відповідно до guardrails.
3. Фіксувати технічні рішення у vault через MCP.
4. Шукати релевантні вимоги й рішення перед зміною коду.

## Межа даних

База знань — окремий GitHub-репозиторій `studyflow-knowledge-base`. У цьому репозиторії немає її файлів. Агент читає та оновлює нотатки через локальний MCP-сервер `studyflow-vault`.
